## Independently selected policy wire shape

Policy schemaVersion is exactly1. All objects are closed and reject duplicate/missing/unknown
properties. Root fields: schemaVersion,id,version,evidenceMap,requiredCapabilityIds,
semanticOnlyCapabilityIds,knownPlatforms,environments,supportedEvidenceFormats,
maximumPreflightSeconds,maximumScaffoldSeconds,toolProbes,archives. The raw digest is supplied
separately by the explicit caller and recorded in policy identity. It is never a trust grant.

EvidenceMap fields are id,version,digest,mappings. Each mapping has format,id,version; format is
an opaque exact key. Its semantic digest is SHA256 of compact UTF8 JSON of mapping objects sorted
ordinally by format, object field order format,id,version and System.Text.Json default string
escaping, no BOM/newline. Duplicate keys refuse. Supported formats have id/version separately.
Environment rows have id/environment, with only local,ci,local-or-ci,release mapping to Config's
existing classes. These declarations do not satisfy actual host environment admission.
Tool probes have id,executable,arguments,versionPrefix,versionSuffix,maximumOutputCharacters;
argv values remain literal and the capture maximum is positive at most1MiB. Archive associations
have templateSource,packageId,packageVersion; no archive digest is inferred from a source string.
Versions are exact literals, budgets positive integers, identity lists distinct.

The first profile uses Linux-x64/glibc, pidfd_spawn and held directory descriptors. Atomic
renameat2 NOREPLACE publishes into the held parent object and preserves an appearing target.

descendants; pathname relocation can leave requested-path commit Unknown. No sandbox is claimed.

## Exact co-tenant tool-manifest composition join

The catalog edge reuses the actual shared tool manifest seed/merge at only the normalized
`.config/dotnet-tools.json` path. It retains original template bytes/hash separately from
final merged bytes/hash. Existing co-tenant entries/root metadata remain; missing exact
SDD/Coordination selections are added, conflicting selections refuse, and an already complete
manifest is not rewritten. The catalog edge refuses invalid UTF8/JSON and duplicate property
names before the shared merge; legacy callers retain their existing behavior.

An absent manifest is SDD-owned only after the seed actually lands. A hybrid entries-only merge
keeps provider whole-file ownership. Exact post-write bytes must equal the shared seed/merge of
the captured original, under the held original physical file identity, before composed provenance
or commit. The pure workflow recognizes this exact-path hash amendment while preserving all other
payload/process/tool/archive observations; that correspondence grants no physical execution or
arbitrary manifest mutation authority. First refusal/unknown cleanup stays owned under original
phase ends. No new schema, public API, package or lifecycle authority is introduced.
