# Typed SDD preview 1.4.0-preview.1

`FS.GG.SDD.* 1.4.0-preview.1` adds the Typed SDD representation backend while retaining Standard SDD
as the default. The release includes lifecycle selection, authority manifests, canonical F# authoring,
inspection, migration classification and rollback, installed skills, and distinct failure identities.

This is an additive minor preview. `FS.GG.Contracts` remains independently versioned at 7.5.2.
