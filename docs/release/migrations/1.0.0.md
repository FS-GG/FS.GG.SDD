# Migration to `1.0.0`

## Summary

`1.0.0` makes observed test evidence byte-exact. A receipt now identifies the SHA-256 of the exact
artifact bytes, including a UTF-8 BOM and line endings. Verification and shipping re-read those raw
bytes and block after any mutation.

## Breaking changes and adaptation

| Change | Adaptation |
|---|---|
| `ObservedRun` adds `DigestContract`; persisted receipts without `digestContract: exact-bytes-v1` are legacy. | Keep the cited report and run `fsgg-sdd evidence --sync-observed-run <report>` before verify or ship. Do not copy the old digest. |
| `FileSnapshot` adds `RawBytes: byte array option`. | Library consumers constructing snapshots set `RawBytes = None`; filesystem adapters preserve the exact bytes as `Some bytes`. |
| `TestReport.parseBytes` and `SchemaVersion.sha256Bytes` are added. | Evidence producers use `parseBytes`; text-only callers may retain `parse` for its historical normalized-text behavior. |

The persisted evidence schema remains version 1 because `digestContract` is additive at the codec
level. Its absence has an explicit legacy meaning and is never silently interpreted as byte-exact.
