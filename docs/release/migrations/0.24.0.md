# FS.GG.SDD 0.24.0 migration

This release adds the optional `evidence[].performanceBudget` mapping. Existing schema-v1 evidence
files need no edits: no mapping means no active performance acceptance target, preserving prior
baseline and stress-report behavior.

Once a mapping is authored, SDD fails closed. Missing or malformed artifact targets/workloads,
capability or scope mismatch, over-budget p95/p99, excess catch-up, and required-but-absent live
compositor proof block evidence/verify/ship. A `deferralIssue` remains blocking debt rather than a
pass.
