# Migration to `2.0.0`

## Summary

`2.0.0` binds an observed test receipt to the immutable source candidate that was executed. Verification
and shipping permit a later receipt/readiness-only commit, but block after any source, policy, lifecycle,
or non-receipt evidence change. Synchronizing a regenerated report preserves its original candidate and
cannot relabel an old report to a newer commit.

## Breaking change and adaptation

| Change | Adaptation |
|---|---|
| The public F# `ObservedRun` record adds `CandidateCommit: string`, changing its positional constructor arity. Persisted receipts without `candidateCommit` are legacy. | Library consumers constructing `ObservedRun` add the full immutable Git commit id that was tested. Repository users keep the cited report and run `fsgg-sdd evidence --sync-observed-run <report>` while still on the original candidate; after a source successor, rerun the suite and record a new receipt. |

The persisted evidence schema remains version 1 because the field has an explicit legacy interpretation:
absence never silently means “current candidate.”
