# FS.GG.SDD 0.30.0

This release is additive. Existing unclassified and `{gameplay}` requirements retain their current
evidence semantics.

Projects may opt into `{production-journey}` for user-visible boot, reachability, progression, or
terminal behavior. Such requirements require a schema-v1 journey receipt emitted by FS.GG.Game
0.12.0 and bound to the same passing observed test report. SDD preserves the separate journey count
through evidence, verify, ship, and `governance-handoff.json`.
